# Images

Drop your images here using these exact file names. Until they exist, the site shows styled placeholders.

| File | Used for | Recommended size |
| --- | --- | --- |
| `banner.png` | Hero banner on the home page | 1920x1080, landscape |
| `logo.png` | Company logo (navbar and brand section) | Transparent PNG, ~400px wide |
| `product-1.png` | Vitamin C Glow Serum | 800x800, square |
| `product-2.png` | Hydra Cloud Moisturizer | 800x800, square |
| `product-3.png` | Gentle Foam Cleanser | 800x800, square |
| `product-4.png` | Invisible Shield SPF 50 | 800x800, square |

To use different names or formats (e.g. `.webp`), update the paths in `lib/products.ts`.
